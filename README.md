# Python Recon Tools

Herramientas prácticas de **reconocimiento y OSINT** hechas en Python.

## Características
- Scripts de enumeración
- Recolección de información pública
- Utilidades de análisis
- Fácil de extender

## Estructura
```
├── modules/
├── scripts/
├── data/
└── examples/
```

## Requisitos
```bash
pip install -r requirements.txt
```

## Uso
```bash
python scripts/basic_recon.py target.com
```
